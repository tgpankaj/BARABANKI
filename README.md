A modern, responsive, community-driven civic web platform built specifically for the residents, students, businesses, artisans, job seekers, and visitors of **Barabanki, Uttar Pradesh, India**.

---

## 🌟 Vision & Overview

Barabanki is a culturally vibrant and historically rich district situated adjacent to the state capital Lucknow, renowned for the mystical shrine of **Deva Sharif (Haji Waris Ali Shah)**, the ancient **Lodheshwar Mahadev Temple** at Mahadeva, the celestial **Parijaat Tree** at Kintoor, and its age-old **Handloom and Textile weaving traditions**.

**Barabanki Connect** brings the district into the digital era with:
1. **Local News & Bulletins**: Verified civic news, developmental announcements, and educational bulletins with full source attribution.
2. **Local Events & Festivals**: Cultural fairs (Deva Mela, Mahadeva Mahotsav), workshops, and community events with calendar views, RSVP registrations, and interactive maps.
3. **Local Business Directory**: Local textile weavers, handicraft artisans, shops, healthcare providers, restaurants, and professional services across tehsils (Nawabganj, Ramnagar, Fatehpur, Haidergarh, Rudauli, Zaidpur).
4. **Jobs & Career Portal**: Opportunities for local youth and graduates from institutions like JNT, Sagar Institute, TRC, and local ITIs.
5. **Education & Skills Hub**: Directory of degree colleges, technical institutes, competitive coaching centers, and admission notices.
6. **Community Forum & Feed**: Public civic discussions, issue reporting, neighborhood updates, likes, comments, and citizen feedback with active moderation.
7. **Civic Grievances & Public Problems (Screen 8)**: Community tracking for potholes, sanitation, water supply, electricity, and streetlights with status lifecycles, "Me Too" upvoting, and admin audit trails.
8. **Creators & Artisans Showcase**: Profiles for master weavers (Zari, Chikan, handloom scarves), writers, poets, and digital creators with follow/unfollow capability.
9. **Tourism & Heritage**: Curated visitor guides with OpenStreetMap coordinates, historical context, and visitor guidelines.
10. **Emergency & Civic Helplines**: Quick access to local police (112), district hospital (108), women powerline (1090), cyber crime cell (1930), and district control room (05248-222001).
11. **In-App Persistent Notifications**: Notification center with real-time unread badges in the navbar.
12. **Interactive Admin Portal**: Real-time KPI statistics via Chart.js, content moderation queues, user management, and verified badge controls.

## 🏗️ Architecture & Technology Stack

- **Backend**: Python 3.12 / 3.11 with **FastAPI** (High-performance ASGI framework)
- **Templating**: **Jinja2** for server-rendered, SEO-friendly HTML with fast time-to-first-byte
- **Frontend**: Clean **HTML5, CSS3, Modern ES6+ JavaScript** (Responsive design system, WCAG accessible skip links, mobile bottom navigation)
- **Database & ORM**: **PostgreSQL 18** with **SQLAlchemy 2.0** ORM (includes zero-config SQLite auto-fallback for local development)
- **Database Migrations**: **Alembic** schema migrations with autogenerated revisions and batch DDL support
- **Authentication**: Secure **bcrypt** password hashing, HTTP-only session cookies with role-based access control (Admin, Moderator, Business Owner, Creator, Resident), plus JWT bearer tokens for REST APIs
- **Forms & Security**: Pydantic v2 data validation, HMAC-SHA256 CSRF protection, Content-Security-Policy (CSP), security headers (nosniff, SAMEORIGIN, Referrer-Policy, Permissions-Policy), sliding-window rate limiting, and custom 404/500 handlers
- **Performance**: GZip response compression (responses >500 B), Cache-Control caching for static assets (24h)
- **Maps**: **Leaflet.js** with OpenStreetMap tiles (no paid API key required)
- **Charts**: **Chart.js** for admin analytics and civic metrics
- **Testing**: **pytest** with test database fixtures, `httpx`, and client runners

## 🚀 Quickstart Guide (Windows PowerShell)

Follow these exact Windows PowerShell commands to install, configure, migrate, and run the application.

### 1. Prerequisites
- Python 3.10+ (Python 3.11 or 3.12 recommended)
- Git for Windows
- PostgreSQL 16+ (Optional for local development; SQLite works out-of-the-box)

### 2. Open PowerShell and Navigate to the Project

```powershell
cd C:\Users\hp\OneDrive\Desktop\Projects\Barabanki
```

### 3. Create or Activate Virtual Environment

```powershell
# If virtualenv does not exist yet:
python -m venv venv

# Activate virtual environment:
.\venv\Scripts\Activate.ps1
```

> **Note**: If PowerShell shows an Execution Policy error, run: `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

### 4. Install Dependencies

```powershell
.\venv\Scripts\python.exe -m pip install --upgrade pip
.\venv\Scripts\pip.exe install -r requirements.txt
```

### 5. Configure Environment Variables

Copy `.env.example` to `.env`:
```powershell
Copy-Item .env.example .env
```

The default `.env` is pre-configured for instant local development with SQLite (`sqlite:///./barabanki.db`).

#### (Optional) Configure PostgreSQL:
If you want to connect to a local PostgreSQL instance:
```powershell
# Edit .env and set your PostgreSQL connection string:
# DATABASE_URL=postgresql+psycopg2://postgres:YOUR_PASSWORD@localhost:5432/barabanki_db
```

### 6. Initialize Database, Run Migrations & Seed Baseline Data

Execute the unified database setup script. This script applies Alembic migrations up to head and seeds authentic Barabanki baseline data:

```powershell
.\venv\Scripts\python.exe init_db.py
```

Alternatively, you can run Alembic migrations directly:
```powershell
# Run migrations to latest head:
.\venv\Scripts\python.exe -m alembic upgrade head

# Seed baseline data:
.\venv\Scripts\python.exe -m app.seeds.seed_data
```

This seeds:
- **Admin Account**: `admin@barabanki.local` / `Admin@123456`
- **Moderator Account**: `moderator@barabanki.local` / `Moderator@123456`
- **Resident Account**: `citizen@barabanki.local` / `Citizen@123456`
- **Artisan Account**: `artisan@barabanki.local` / `Artisan@123456`
- Authentic tourist landmarks: Deva Sharif, Parijaat Tree, Lodheshwar Mahadev, Barabanki Clock Tower.
- Authentic educational institutions, handloom clusters, local news, and community discussions.

### 7. Run the Application

#### Development Server (with Auto-Reload):
```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --reload --port 8000
```

#### Production Server (Multi-Worker, Optimized):
```powershell
.\venv\Scripts\python.exe -m uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4 --proxy-headers
```

Open your browser at:
- **Web App**: [http://localhost:8000](http://localhost:8000)
- **Interactive Swagger API Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **ReDoc API Documentation**: [http://localhost:8000/redoc](http://localhost:8000/redoc)
- **Admin Control Center**: [http://localhost:8000/admin](http://localhost:8000/admin) (Log in with `admin@barabanki.local` / `Admin@123456`)
- **System Health Endpoint**: [http://localhost:8000/health](http://localhost:8000/health)

## 💾 Database Backup & Restoration

An automated hot-backup utility is included in `scripts/db_backup_restore.py`:

```powershell
# Create an immediate hot backup:
.\venv\Scripts\python.exe scripts/db_backup_restore.py --backup

# List existing backups:
.\venv\Scripts\python.exe scripts/db_backup_restore.py --list

# Verify backup integrity:
.\venv\Scripts\python.exe scripts/db_backup_restore.py --verify backups/barabanki_backup_YYYYMMDD_HHMMSS.db

# Restore from a backup:
.\venv\Scripts\python.exe scripts/db_backup_restore.py --restore backups/barabanki_backup_YYYYMMDD_HHMMSS.db
```

## 🛡️ Security & Privacy Architecture

- **Password Storage**: Multi-round bcrypt hashing, never plaintext.
- **Session Security**: HTTP-only session cookies (`barabanki_session`), SameSite protection.
- **CSRF Protection**: Cryptographic HMAC-SHA256 tokens validated on all state-modifying POST endpoints.
- **Role-Based Authorization**: Hierarchical server-side dependencies (`require_admin`, `require_moderator_or_admin`, `require_auth`).
- **Input Validation**: Strict Pydantic v2 schemas for all API payloads and HTML forms.
- **Real Data Policy**: Authentic Barabanki cultural and civic data attributed to official sources; demonstration entries clearly badged.
